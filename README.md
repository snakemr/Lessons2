**Практикум по Jetpack Compose / Compose Multiplatform**

Проект предназначен для запуска в **IntelliJ IDEA** либо **OpenIDE**. 

Используется Desktop-версия фреймворка Compose Multiplatform поверх встроенной в IDE платформы JDK-21/25. Частично имитируются некоторые функции Android.

**Порядок работы:**

1. Запустите в обычном режиме, либо в режиме автообновления (приложение обновляется автоматически при редактировании кода)
2. При первом запуске укажите своё имя
3. Выберите главу на левом экране
4. Выберите задание
5. В правой части – то, что вы должны получить в итоге
6. Нажмите кнопку **≡** внизу экрана, чтобы прочитать инструкции к выполнению
7. Файлы [src/main/kotlin/**Lesson№x№**.kt](src/main/kotlin/Lesson1x1.kt) — Ваши рабочие файлы на языке **Kotlin** с использованием фреймворка **Compose** в соответствии с заданием
8. Найдите в проекте файл Lesson с номером выбранного задания
9. Выполните задание
10. Перезапустите приложение или дождитесь его автообновления
11. Кнопка ⌛ вверху включает и отключает выполнение тестов
12. Все работы проверяются автоматически при помощи встроенных тестов.
